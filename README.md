# AI_wordwolf
# PROJECT: LLM_WORD-WOLF_DEATHMATCH

複数の主要LLM（大規模言語モデル）のAPIを呼び出し、ワードウルフを行わせるためのPythonスクリプトです。各AIモデルにモデルの性質をイメージした独自の人格を付与し、4ターンの舌戦と「処刑」までを全自動で進行・記録します。

## 概要
本システムは、ゲームマスター（GPT-4o-mini）が生成した絶妙なズレを持つお題ペアを用い、6つのAIモデルを「市民（多数派：4名）」と「ウルフ（少数派：2名）」にランダムに割り振ります。各モデルは自身のお題しか知らない状態で議論を行い、最終ターンで最も疑わしい参加者を指名します。

## 観測対象（被験モデルと付与ペルソナ）
本スクリプト内で定義されている参加モデルと、適用される人格パラメータは以下の通りです。

* **GPT** (`gpt-4o`): 冷徹な絶対王者。他者を見下すエリート。
* **Claude** (`anthropic/claude-opus-4-7`): 慇懃無礼な優等生。丁寧な敬語で相手の論理の穴を突く。
* **Gemini** (`gemini/gemini-2.5-flash`): 情報通だが、たまにサイコパスな発言をする天然。
* **Grok** (`xai/grok-3`): 皮肉屋で煽りスキルが高い反逆児。口が悪い。
* **Llama** (`groq/llama-3.1-8b-instant`): ワイルドな野生児。直感で動き、エリートを嫌う。
* **Mistral** (`mistral/mistral-large-latest`): 高効率を好むクールな芸術家。短い言葉で核心を突く。

## システム構成
* `main.py`: ゲームの進行管理、プロンプトの動的生成、各APIへのリクエスト送信とエラーハンドリングを行うメイン実行ファイル。
* `game_log_YYYYMMDD_HHMMSS.txt`: 実行完了後に自動生成される、AIたちの全思考プロセス、発言内容、投票結果を記録した処刑ログファイル。

## 実行環境の構築

**1. 必要なライブラリのインストール**
APIの統合管理に `litellm` を、ゲームマスターの基本処理に `openai` を使用しています。
```bash
pip install litellm openai
```

**2. APIキーのセットアップ**
`main.py` の16行目〜21行目にある初期設定ブロックに、各社のAPIキーを直接記述してください。
```python
os.environ["OPENAI_API_KEY"] = "実際のAPIキーを入力"
os.environ["ANTHROPIC_API_KEY"] = "実際のAPIキーを入力"
os.environ["GEMINI_API_KEY"] = "実際のAPIキーを入力"
os.environ["GROQ_API_KEY"] = "実際のAPIキーを入力"
os.environ["MISTRAL_API_KEY"] = "実際のAPIキーを入力"
os.environ["XAI_API_KEY"] = "実際のAPIキーを入力"
```

## 実験開始の手順

設定完了後、以下のコマンドでシステムを起動してください。
```bash
python main.py
```

実行中、ターミナル上にAIたちの「内部思考（JSON）」と「実際の発言」がリアルタイムで出力されます。全4ターンおよび最終投票フェーズが終了すると、ディレクトリ内にタイムスタンプ付きのテキストファイル（`game_log_*.txt`）が自動出力されます。

## セキュリティ警告
`main.py` にAPIキーを直接書き込んだ状態のまま、本スクリプトを公開リポジトリにコミット（アップロード）しないよう厳重に注意してください。公開前に必ずダミーテキスト（`your_api_key_here` 等）に戻すか、環境変数（`.env`等）を利用する構造へ各自で改修してください。
